## 🔨 Building

☑ = shipped and running · ☐ = in progress

### Arabic / English RAG platform
Retrieval over text, PDF and scanned documents in Arabic and English, with measured answer quality and a deploy gate.

`Python` `PostgreSQL` `pgvector` `Claude` `LangGraph` `Docker` `Google Cloud` `GitHub Actions`

- ☐ Hybrid search (keyword + vector) with reranking
- ☐ Eval harness, plus a CI check that blocks changes that make answers worse
- ☐ Tool-using agent: raw LLM APIs first, then rebuilt in LangGraph
- ☐ Deployed on Google Cloud (Docker, Terraform, CI/CD) with latency, cost and drift monitoring

### Applied ML: classifier with experiment tracking
`Python` `scikit-learn` `MLflow` `Vertex AI`

- ☐ Binary classifier on a real dataset: precision, recall and AUC with confidence intervals, plus a model card
- ☐ 3+ runs compared in MLflow, one promoted with a written reason
- ☐ Deployed to a Vertex AI endpoint

### LLM command-line tool
`Python` `Pydantic` `httpx` `asyncio` `pytest` `Docker`

- ☐ Streams structured LLM answers, validates them against a schema, retries with backoff, fails clearly on bad output
- ☐ Packaged and tested, shipped as a Docker image with the API key supplied at runtime
